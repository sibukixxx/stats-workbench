# 線形モデルと回帰診断の基盤を導入する

- ステータス: open
- 優先度: high
- 進捗: 企画
- 最終更新: 2026-03-18

## 背景

- 相関係数だけでは予測・説明・因果仮説の検証に進めない
- ユーザーが挙げた単回帰、重回帰、変数選択、残差分析、多重共線性、L1正則化、回帰診断は現在すべて未実装
- プロ向け統計システムとしては、推測統計コアの次に線形モデル基盤が必要

## この課題でカバーする領域

- 単回帰
- 重回帰モデル
- 予測値と予測区間
- 回帰係数の推定と検定
- 決定係数、調整済み決定係数
- 残差分析
- 多重共線性
- 回帰診断
  - leverage
  - 外れ値影響
  - Q-Q プロット
  - DW 比
- 変数選択
  - 第1フェーズは stepwise ではなく明示列指定を優先
  - L1 正則化は第2フェーズ候補

## システム変更の要点

- `sf-core`
  - `StatsKind` / `Artifact` に回帰結果と診断結果の表現を追加
  - recipe step と model artifact schema を定義
- `sf-stats`
  - OLS を実装
  - 標準誤差、t値、p値、信頼区間、VIF、残差統計を返す
- `sf-engine`
  - model 系 step を追加
- `sf-cli`
  - 例: `sf model regress`, `sf model diagnose`
- `sf-report`
  - 係数表、診断表、残差関連の plot/table 出力を追加

## スコープ上の判断

- 第1フェーズは OLS と回帰診断を優先し、ロジスティック回帰や一般化線形モデルは次フェーズへ分離
- 因果推論機能までは入れず、あくまで回帰分析基盤として切る

## 完了条件

- 単回帰と重回帰を CLI / recipe から実行できる
- 係数表に推定値、標準誤差、t値、p値、信頼区間が出る
- 残差・VIF・DW 比・leverage の最低限の診断結果が出る
- 予測値と予測区間を出力できる

## 次の一手

- 最初の着手は OLS の係数推定と係数表出力
- その後に残差分析、VIF、DW 比を積む
